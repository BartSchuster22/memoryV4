# MemoryV4 QA10 Scorecard

Current phase: governed lifecycle complete, not full QA10.

| # | Gate | Status | Evidence / limitation |
|---|---|---|---|
| 1 | Migrations | partial | `0001_foundation` through `0004_record_lifecycle` are ordered/reversible; fresh schemas, upgrades, rollback, and lifecycle guards are tested. Upgrade-from-real-V3 is not_implemented. |
| 2 | Storage-seam parity | partial | `Store` protocol and `SqliteStore` adapter exist. Byte-identical V3 parity workload is not_implemented. |
| 3 | Retrieval quality | partial | FTS5/lexical search has graph filters and cursor pagination. Hybrid vector/RRF and recall benchmarks are not_implemented. |
| 4 | Governance ranking | not_implemented | No bounded governance prior or property tests yet. |
| 5 | Supersession + contradiction integrity | partial | Atomic bidirectional supersession, terminal-state guards, archive/expiry restoration, idempotency, and concurrency pass. Health-worker contradiction detection is not_implemented. |
| 6 | Provenance + orphan scan | partial | Records, relations, and artifacts carry provenance; link creation enforces scoped target existence. Background orphan scans and canvas resolution are not_implemented. |
| 7 | Idempotence + decay safety | partial | Actor-scoped mutation idempotency, conflict detection, exact replay, and concurrent claim serialization pass. Distillation/health idempotence and decay safety are not_implemented. |
| 8 | Scope isolation | partial | Entity/record/relation/artifact list/direct/search/context paths share ancestor visibility; sibling reads and graph edges are denied. Public curation workflow is not_implemented. |
| 9 | Security | partial | Action permissions, write policies, actor derivation/delegation, canonical restrictions, denial audit, and constant-time keys pass. Rate limits and broader hardening are not_implemented. |
| 10 | Durability | partial | SQLite WAL, quick_check, optimistic versions, and concurrent idempotent writers are tested. Backup/restore, embeddings consistency, and fault injection are not_implemented. |

Unimplemented gates are intentionally marked `not_implemented` rather than `pass`. `make qa10` currently emits a JSON status for automation but is not a full QA10 harness.
